# СЛИЯНИЕ — платформа поведенческой аналитики

**Профессиональный инструмент для экспертной оценки психоэмоционального состояния человека по видео.**

---

## Что делает

СЛИЯНИЕ объединяет **видеоаналитику**, **акустический анализ** и **внешние сенсоры** в единый инструмент эксперта-профайлера:

- **Мимика лица** — 478 точек отслеживания
- **Движение тела** — 33 точки скелета (поза, жесты)
- **Акустика** — тон голоса, речевые паттерны
- **Внешние датчики** — пульс (IoT) по беспроводному каналу

Эксперт ставит метки в моменты значимых изменений. Система:
- Фиксирует данные сенсоров в момент метки
- Привязывает их к таймкоду видео
- Формирует клиентский артефакт: видео с титрами + JSON + отчёт

**Результат:** не оспоримое доказательство экспертной оценки.

## Почему СЛИЯНИЕ, а не аналоги

| Обычные системы | СЛИЯНИЕ |
|---|---|
| Автодетектор «где ложь» | Инструмент эксперта, решения принимает человек |
| Только видео | Мультимодально: видео + звук + сенсоры |
| Чёрный ящик | Прозрачные данные: сенсоры на момент метки |
| Сырые алерты | Готовый артефакт: видео + JSON + PDF |
| Облачные сервисы | **Локальная обработка** (соответствие ФЗ-152) |

---

## Что получает клиент

1. **Видео с титрами** — в момент каждой метки подсвечиваются слова эксперта и данные сенсоров.
2. **JSON с метками** — для интеграции с системами клиента.
3. **PDF-отчёт** — сводка по всем меткам с комментариями и данными.

Формат клиентской версии **не содержит личной информации эксперта** — только факты и данные.
