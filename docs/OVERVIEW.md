# СЛИЯНИЕ — обзор продукта

**Профессиональная платформа поведенческой аналитики для экспертов.**

---

## Что это

СЛИЯНИЕ — инструмент для **экспертной оценки психоэмоционального состояния человека по видео**. Работает локально, без отправки данных в облако.

Эксперт смотрит видео и ставит **метки** в моменты значимых изменений. Программа фиксирует **все данные сенсоров** в момент метки и формирует клиентский артефакт.

---

## Как работает

**Три источника данных синхронизируются:**

| Источник | Что анализируется |
|---|---|
| **Видео лица** | 478 точек мимики, микродвижения глаз, бровей, губ |
| **Поза тела** | 33 точки скелета: плечи, руки, наклон корпуса |
| **Акустика** | Тон голоса, речевые паттерны (паузы, заминки) |
| **Внешние сенсоры** | Пульс с IoT-устройства по беспроводному каналу |

**Эксперт работает в паузе:**

1. Заметил момент → **пауза**
2. Ставит **метку** с классом состояния (LIE / FEAR / HATRED / MASK_PERSONA / ...)
3. Пишет короткий комментарий → **текст для титров**
4. Опционально записывает длинный голосовой комментарий для себя
5. Продолжает просмотр
